# Colour Generator 🎨

A simple React app that generates a random background color every time you click the button.

## 🔗 Live Demo
https://livasf.mimo.run/

## 🛠️ Tech Stack
- React (useState hook)
- HTML
- CSS

## ✨ Features
- Click "Change Color" to generate a random color
- Displays the current hex color code
- Simple, clean UI

## 📸 Preview
A card-style UI showing the current color name/hex code with a button to generate a new one.
